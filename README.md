# Fluent progress — German

This branch holds saved progress for the Fluent language-tutor plugin
(https://github.com/m98/fluent) for **German** only. Italian lives on the
separate `fluent-progress` branch; the two never mix.

Cloud sessions in the "Fluent German" environment check out this branch at
`~/.claude/fluent-data` (the plugin's default data folder). `autosave.sh` runs
after each Claude reply and commits and pushes any changes back to this branch.

Don't merge this branch into any other branch; it shares no history with them.
